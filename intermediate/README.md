# TalentRoute — Intermediate learner-support triage

Mouza Al Darmaki · MAAI7101. OULAD university learners are scored at day 28 for Success, Fail or Withdrawn. Classification and engagement outlier detection were compared under one staff-minute budget. The provisional reference is classifier-only: detector benefit is unconfirmed. Targeting coverage is not intervention effectiveness.

## Reproduce
Install uv and just, then run:
```sh
just install
just pipeline
just app 300
```
Python 3.14 is pinned; no GPU, credentials or LLM API. Prior analytical runtimes: Mac 41.91s, Linux 84.66s; installation/network extra. Historical checks concern their named snapshots; current verification accompanies delivery.

Open review/decision_room.html, review/index.html or review/report.html offline, keeping sibling docs/outputs folders. The pipeline regenerates reports, figures, diagnostics and tests; just clean removes generated artifacts, retaining raw data.
