What if this queue takes longer than planned?

Keep the current case list fixed and increase the assumed time per action. A shortfall means that list cannot be completed within the available minutes. Compare an explicit deferral rule with planning a new queue at the higher cost.

Deferral keeps the highest-risk original alerts first, then the highest-risk original reviews that fit. Other cases are deferred; action types are unchanged. Lower-risk alerts can be retained while higher-risk reviews are deferred. This is an example contingency, not an optimal or approved workflow. Coverage describes historical outcomes reached, not outcomes prevented. Effort is per course case.

Conditional value of these actions
